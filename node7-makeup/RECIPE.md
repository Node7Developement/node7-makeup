# node7-makeup recipe

1. Place `node7-makeup` in `resources/[node7]/`.
2. Ensure `oxmysql` and `node7-core` start first.
3. Add `ensure node7-makeup` after `node7-barbers`.
4. Restart the resource or server.
5. Stand at a configured barber chair and use the visible K interaction.

There are no commands, fallback commands, map blips, or permission entries.
